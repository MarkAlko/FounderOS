# Locale

Hebrew (`he`, `dir=rtl`) is the default for a browser with no `mrk-locale` cookie. English (`en`) is the fallback and a Settings choice. The cookie is read on the server so the first paint already has `lang` and `dir`.

Translated in this iteration:

- Sidebar groups and items, and the matching command-palette view names
- Settings title, language control, appearance heading, modules heading
- Home greeting and the main console headings (systems, agents, inbound, runs, pages, activity, brain freshness, details, finances strip)
- Page titles for finances, connections, knowledge visualizer, Optimal Engine, and the agents roster when it is the sample board

Rubik (SIL OFL, `app/fonts/OFL-Rubik.txt`) covers Hebrew and Latin on `html[lang=he]`. Geist stays the English face. `code`, `kbd`, and `.font-mono` stay on the mono face and isolate as LTR.

Still English, on purpose for this increment: workflow canvas chrome, funnel body, inbox thread chrome beyond the sample notice, Blueprint canvas, trading, social, lab, creative engine, wizard body, and most table headers inside a module. Missing dictionary keys fall back to English.
